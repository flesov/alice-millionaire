# 🎯 Кто хочет стать миллионером?

Навык Яндекс Алисы на Flask — голосовая игра-викторина с 15 вопросами нарастающей сложности, тремя подсказками и таблицей рекордов.

## Возможности

- 15 вопросов по категориям: история, наука, география, литература и др.
- Денежная лестница до 1 000 000 ₽ с несгораемыми суммами (5 000 и 50 000 ₽)
- Три подсказки: «50 на 50», «Помощь зала», «Звонок другу»
- Таблица рекордов топ-10, сохраняется между сессиями
- Поддержка одновременных сессий нескольких пользователей

## Стек

Python 3.10 · Flask · Яндекс Диалоги · tuna

## Структура


├── app.py           # Flask-сервер, вебхук
├── game.py          # игровая логика
├── questions.py     # вопросы и денежная лестница
├── leaderboard.py   # таблица рекордов
└── requirements.txt
